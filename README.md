# Divij Verma Portfolio

Personal portfolio site built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting started

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
